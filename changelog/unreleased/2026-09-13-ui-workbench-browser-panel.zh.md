# 工作台的面板变成了一个浏览器：地址栏右边那个箭头就是「选择元素」

- **Date:** 2026-09-13
- **Type:** change
- **Scope:** `web`

[English](2026-09-13-ui-workbench-browser-panel.md)

面板现在长得像一个浏览器，而不是一个表单。**地址栏那一行**是它唯一常驻的 chrome：状态点、地址、回车图标的载入按钮、刷新，以及**右边那个箭头**——按它进入选择模式，再按一次退出，和 DevTools 里的「选择元素」一样。页面加载正常时，地址栏下面**不再有任何一行**；只有在失败、还没载入、或者页面的档位不是精确档时，才多说一句。选择行也随之合并成一行：`[多选][清除][已选中的元素 / 候选] [加入对话]`。

## 细节

- **状态条撤掉，状态回到它该在的地方**：地址左边那个点的**颜色**是状态，整句话（`已连接 · 地址 · 档位`）在它的悬停提示与无障碍名里。原来那行 `已连接 · http://… · 精确档可用` 每一秒都在占预览的高度，而它 99% 的时间说的是"没事"。
- **载入按钮变成回车符号**：浏览器没有"载入"按钮，它有这个键。无障碍名仍是「载入」，所以按键名找它的脚本不受影响；地址框里按回车也仍然是载入。
- **选择元素的开关搬进地址栏，并且默认关**。它是个 `aria-pressed` 的图标按钮：按下进入选择模式（页面开始高亮、点击被拦），再按退出（页面完全归你）。**面板一打开是普通浏览器**——不点它，页面就是页面。
- **「暂离」删掉了**（`workbench-state.ts` 里的 `paused` / `pickMode: "paused"` / `pause`·`resume` 两个事件一起去掉）。暂离要办的事是"页面归我，但我的选中别丢"，而**箭头关掉就是这件事**：`toggle` 只翻 `wanted`，从不碰 `picked`。两个入口做同一件事，留下的是那个本来就是这个功能的开关。
- **原位换成「清除」**：一次把这一批清空（每条 chip 自己的 × 保留），而且**不退出选择模式**——清空一批不是不想选了。它站在多选之外，因为它是关于"已经选中的东西"的，退出选择模式之后也还得够得着。
- **载荷卡整块撤掉**（字段行、JSON 折叠、`data-workbench-payload` 一起删）。面板不再把载荷摆在用户眼前；载荷链路一个字没动，它仍然随「加入对话」进 composer 的 chip、随消息发出去。**代价是明摆着的**：那曾是用户在发送前唯一能读到载荷的地方（chip 上只有名字与 `refId` 的 tooltip），所以"先摆给你看"这道闸门没有了，"你自己点加入对话"仍是唯一入口——面板里那条「已知边界」（回传通道那一句）已按这个事实改写。
- 选择行里的计数不再是画出来的数字，而是容器的无障碍名（`已选中 3 个`）；`data-workbench-count` 还在，给脚本用。

## 实测

- 新真机脚本 `实测脚本/m60-面板形态/`（端口 5194，真桌面壳）：**29/29**，9 张截图。量到的：载入后面板文本里查「已连接」= 0 次（它只在点的 `aria-label` 上）；默认 `aria-pressed=false` 且页面侧 `{active:false}`；选择行出现前后预览高 650px → 587px；关掉箭头后 `{active:false, picked:2}` 且两个 chip 仍在；清除之后 `{active:true, multi:true, picked:0}`（还在选择模式里）；发出去的消息里载荷是 `v1`、位置等于 AST 真值。
- 单测（web 包 **2086/2086**，148 个文件）里钉住那条凭据：`keeps the picks when the arrow is switched off — which is why 暂离 is gone`，以及 `empties the batch on one 清除, and keeps the page it was picked on`。
- typecheck / format:check / oxlint（0 错 0 警）/ build 全绿；全仓 web e2e（59 条）与改动前的基线逐条比对：**没有新增一条红**。

## 边界

- **英文界面没有真机**：只过了 `Strings` 两本字典的同形/占位符单测。
- **载荷的"发送前预览"没有了**，这是这次真正的取舍，写在决策日志 D33 里；要恢复的话，最自然的位置是 composer 里那个 chip。
- 以载荷卡为观测面的旧实测脚本（`实测脚本/` 里的 m26 / m27 / m31 / m33 / m34 / m41 / m43 / m51 / m53 / m56 / m57 / m58）**对着的是已经不存在的那块 UI**，用之前要先改成从消息里读载荷；`m54` / `m56` / `m57` 量的就是卡片那一层，观测对象要重新定义。
